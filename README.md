# The Fitness Freak Gym

A single-page website for The Fitness Freak Gym in Chandan Nagar / Kharadi, Pune.

## Features

- Strength and conditioning focused gym presentation
- Responsive layout for desktop and mobile screens
- Interactive Three.js WebGL background
- GSAP scroll and entrance animations
- Smooth scrolling with Lenis
- Lucide icons and custom web typography

## Run locally

No build step is required. Open `index.html` directly in a browser, or serve the folder with any static HTTP server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

The page loads its animation, icon, and font libraries from public CDNs, so an internet connection is required for the complete experience.
